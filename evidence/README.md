# Evidence

- `LATEST.md` - the most recent proof drill report (copied from the newest `drill-*` folder).
- `drill-<time>/report.md`, `report.json`, `drill.log` - one folder per drill run, human and machine readable.
- `screenshots/` - screenshots taken during the demo (pipeline, dashboard, alert firing, HTTPS padlock).

Reports are generated by `python3 scripts/drill.py`; nothing in them is typed by hand.
